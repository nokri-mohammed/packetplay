- **Findings (ranked):**
  1. Low, `src/layout.ts:65` (pinned `at`) with `schema/scene.schema.json:125-133`: `at` has no
     `minimum`, and the validator (`src/validate.ts`) has no check on it, so a negative `at` such as
     `[-1, 0]` gives a node at a negative x (outside the viewBox). Auto rows are normalised to min 0
     (`src/layout.ts:143-148`) but pinned nodes are not, and `maxCol`/`maxRow`
     (`src/layout.ts:159-160`) only grow the canvas on the high side. Fix: add `"minimum": 0` to the
     `at` items in the schema (then run `bun run gen:types`) and a test, or shift the whole layout so
     the minimum cell is 0.
  2. Low, `src/layout.ts:81-82`: `violates` rebuilds the group set from all ids on every candidate
     cell, so placement is O(n^2) to O(n^3) per scene. Harmless for example-sized scenes. Fix if scenes
     grow: compute `groups` once outside `violates`.
  3. Low, `src/render.ts:9-14`: `escapeXml` does not drop characters that are illegal in XML 1.0
     (for example U+0000 to U+0008, U+000B, U+000C, U+000E to U+001F). A label containing one gives a
     malformed SVG. Fix: strip `/[\u0000-\u0008\u000B\u000C\u000E-\u001F]/g` in `escapeXml`, plus a test.
  4. Info, `scripts/render-example.ts:10-11`: `validateScene` returns `Issue[]` (`src/validate.ts:168`),
     but the script casts to `unknown` and probes for `.issues`. It works, but the cast can be removed:
     `const issues = validateScene(scene)`.
  5. Info, `src/icons.ts:29-35` and `src/render.ts:24-27`: `xlink:href` is rewritten by `prefixIds`, but the
     output root has no `xmlns:xlink`, and the icon roots (which declare it) are dropped. No icon body
     uses `xlink:` today, so nothing breaks. Fix only if an icon with `xlink:href` is added: declare
     `xmlns:xlink` on the output root.
  6. Info, already in LESSONS: unscoped `.st0` to `.st5` classes in `block.svg`, and `<style>` is
     forbidden by `test/render.test.ts`.
  No critical, high or medium findings.

- **Lessons:** (a) Schema `at` has no lower bound; add bounds in the schema when a layout depends on
