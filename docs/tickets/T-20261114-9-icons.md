- Manager note (from the T-20261114-7 Report): none of the 37 real icons uses `href="#..."` or
  `xlink:href="#..."`, so the real files cannot prove that rewrite. Export a pure helper
  `prefixIds(body: string, prefix: string): string` and cover it with a NEW test file
  `test/icons-prefix.test.ts` using synthetic input (`id`, `url(#x)`, `href="#x"`,
  `xlink:href="#x"`, an unrelated `href="https://..."` left alone). New test files are allowed here;
  existing tests stay untouched.
