## Goal

A failing, well-named test suite that fully specifies the M1 behaviour of the loader, validator and
router, so tickets 3 and 4 can be implemented against it.

## Context

- Plan: `docs/plans/2026-11-14-svg-scenes.md`, sections "Pipeline" and "Validation" (M1).
- Depends on T-20261114-1 (toolchain, schema, generated types). Read its Report first.
- Modules and agreed public API (put these signatures in the tests as imports, the implementer
  must match them):
  - `src/load.ts`: `loadScene(path: string): Promise<Scene>` and `parseScene(text: string, format: "yaml" | "json"): Scene`.
    Format is chosen by extension (`.yaml`, `.yml`, `.json`), anything else throws a clear error.
  - `src/validate.ts`: `validateScene(scene: unknown): ValidationIssue[]` where
    `ValidationIssue = { path: string; message: string }`. Empty array means valid. Schema errors
    first, then semantic errors. Never throws on bad input.
  - `src/route.ts`: `routeStep(scene: Scene, step: Step): string[]` returns the full node id path
    including `from` and `to`.
- Behaviour to specify:
  - Loader: `examples/webrtc.scene.yaml` and `examples/webrtc.scene.json` produce deeply equal
    models. Malformed YAML and JSON throw an error that names the file and the line when known.
  - Validator, semantic errors with specific messages, for example
    `chapter 2, step 1: node "stn" does not exist` (use 1-based chapter and step numbers), unknown
    track, unknown group, a link naming an unknown node, a self-link, a `via` node that does not
    exist, a `parallel` step with no children, a step with no route (disconnected nodes).
  - Router: shortest path by hop count over undirected links; `via: [a, b]` forces the path through
    a then b in order (shortest sub-path between each pair); `from === to` is an error; no route
    returns an error that names both nodes. Ties are broken deterministically (first link
    declared wins). On `examples/webrtc.scene.yaml`: `client -> sig` is
    `[client, r1, net, sig]`, and `client -> sam` via `[sig]` is
    `[client, r1, net, sig, net, r2, sam]`.
