## Goal

`test/render.test.ts` passes with `src/render.ts`, which turns a scene plus its layout into one
static SVG string. Also add `bun run render:example`, which writes `dist/webrtc.svg` so the CEO can
open the picture in a browser.

- This ticket starts only after `src/layout.ts` and `src/icons.ts` exist, so import and call them,
  never copy their logic (see `docs/LESSONS.md`).
- The snapshot file is created by the tests in ticket 7 or on first run. If the snapshot has to
  change, do not update it blindly: explain the difference in the Report and ask the manager.
- `render:example` loads `examples/webrtc.scene.yaml`, validates it (stop with the issues if any),
  lays it out, renders it with the real icons and writes `dist/webrtc.svg` (`dist/` is gitignored).
  Put the script in `scripts/render-example.ts`.
- Looks are deliberately plain in M2 (the player in M3 adds colour and motion). Keep the CSS inline
  in a `<style>` element inside the SVG, tiny, and light/dark neutral: `currentColor` for lines and
  text, a subtle fill for group rectangles.
